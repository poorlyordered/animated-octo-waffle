# Contract: Roadmap Refresh

The roadmap refresh is a documentation contract rather than an API contract.

## Required Roadmap Shape

- A completed `M39: Roadmap Backlog Refresh` section exists after M38.
- The `Near-Term Recommendation` section names the recommended next slice.
- `Recommended next-slice candidates` lists ordered candidates with enough detail to start the next Spec Kit feature.
- Each candidate preserves no-execution and explicit-approval boundaries where relevant.

## Restart Surface Contract

- `README.md` names the M39 review phase while the branch is active.
- `AGENTS.md` points to `specs/039-roadmap-backlog-refresh/plan.md`.
- `.specify/feature.json` points to `specs/039-roadmap-backlog-refresh`.
