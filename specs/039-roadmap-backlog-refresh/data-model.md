# Data Model: M39 Roadmap Backlog Refresh

## Roadmap Milestone

- `id`: milestone identifier, `M39`
- `name`: human-readable milestone name
- `goal`: short commander-facing outcome
- `deliveredCapabilities`: completed planning outputs
- `validation`: evidence used to approve the slice

## Next-Slice Candidate

- `id`: proposed future milestone identifier
- `name`: concise candidate title
- `domain`: numbers, opportunity, people, shared command loop, or operations
- `purpose`: why the candidate should be considered next
- `boundaries`: explicit non-execution and approval constraints
- `entryCriteria`: evidence needed before starting the slice
