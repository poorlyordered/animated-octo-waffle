# Data Model: Opportunity Decision Handoff

## OpportunityDecisionHandoff

Client-side browser-safe metadata derived after a decision is recorded.

- `decisionId`
- `decisionStatus`
- `sourceBriefId`
- `sourceRecommendation`
- `sourceCount`
- `focus`
- `provenanceMode`
- `message`
- `boundary`

## Existing Data Sources

- `DecisionRecord`
- `CommandBrief`
- `OpportunityIngestionProvenance`

No durable data model changes are required.
