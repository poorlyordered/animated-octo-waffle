# Quickstart: M35 Decision Backend Filtering

1. Run targeted unit tests:
   - `npm test -- decision-list-filters decision-record-store-filters`
2. Run browser smoke:
   - `npm run test:e2e -- command-surfaces.spec.ts`
3. Run the full local gate:
   - `npm run typecheck`
   - `npm run lint`
   - `npm test`
   - `npm run build`
